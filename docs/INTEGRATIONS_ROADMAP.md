# Integration Roadmap

## EHR/EMR Interoperability

- FHIR export/import adapters (Observation, Condition, CarePlan, Encounter)
- HL7 bridge for legacy systems where required

## Identity and Portals

- OIDC/SAML SSO integration for enterprise tenants
- Patient portal session handoff token exchange pattern

## Care Workflow Integrations

- Appointment scheduling handoff
- Telehealth escalation and clinician routing
- Care-team messaging/audit events

## Delivery Phases

1. Read-only FHIR export (pilot)
2. Bi-directional care plan sync
3. Full encounter and messaging integration
