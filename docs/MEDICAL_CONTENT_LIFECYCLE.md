# Medical Content Lifecycle

## Metadata Requirements per Content Asset

- content_id
- title
- author
- reviewer
- guideline references
- effective_date
- expiry_date
- status (draft, active, deprecated)
- source_version

## Lifecycle Stages

1. Draft
2. Clinical review
3. Approved active
4. Superseded
5. Deprecated archived

## Versioning Rules

- Any triage-impacting update requires minor or major version bump.
- Deprecated content must include replacement reference.
- Expired content must be blocked from primary retrieval corpus.

## Traceability

Every content pack should map to authoritative reference family and source version.
